# Feira da Quebrada

**Vitrine digital para empreendedores locais**

A Feira da Quebrada é um projeto acadêmico que busca valorizar o comércio local por meio de um catálogo digital de produtos e serviços. A plataforma tem como objetivo facilitar a divulgação de pequenos negócios e ajudar os moradores a descobrir empreendedores da própria comunidade.

> **Status:** Em desenvolvimento.

## Objetivo

Desenvolver uma plataforma web intuitiva, responsiva e visualmente agradável que reúna produtos e serviços de empreendedores locais, ampliando sua visibilidade e facilitando sua descoberta pela comunidade.

## Problema e solução

**Problema:** pequenos empreendedores e prestadores de serviços podem enfrentar dificuldades para divulgar seus negócios e alcançar novos clientes.

**Solução:** criar um catálogo digital comunitário que permita cadastrar, consultar e organizar produtos e serviços em um único lugar.

## Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização, identidade visual e responsividade.
- **Git e GitHub:** versionamento do código e colaboração entre os integrantes.
- **Figma:** criação da identidade visual e prototipação das interfaces.

## Funcionalidades previstas

- [ ] Cadastrar produtos e serviços.
- [ ] Listar os itens cadastrados.
- [ ] Filtrar itens por categoria.
- [ ] Visualizar os detalhes de um produto ou serviço.
- [ ] Editar cadastros existentes.
- [ ] Excluir cadastros.
- [ ] Validar os formulários.
- [ ] Adaptar a interface para computadores, tablets e celulares.

As funcionalidades serão implementadas e testadas durante o desenvolvimento do projeto.

## Páginas do projeto

| Página | Descrição |
|---|---|
| **Início** | Apresentação da plataforma e destaque dos negócios locais. |
| **Catálogo** | Listagem de produtos e serviços, com filtros por categoria. |
| **Cadastro** | Formulário para adicionar produtos e serviços. |
| **Detalhes** | Exibição das informações completas do item selecionado. |

## Como executar o projeto

O projeto está em desenvolvimento. Quando os arquivos estiverem disponíveis no repositório, será possível executá-lo localmente seguindo estes passos:

1. Instale o Git, caso ainda não esteja instalado.
2. Clone o repositório para seu computador.
3. Abra a pasta do projeto.
4. Abra o arquivo `index.html` em um navegador.

```bash
git clone URL_DO_REPOSITORIO
```

Substitua `URL_DO_REPOSITORIO` pelo endereço real deste repositório.

Como o projeto utiliza HTML, CSS e JavaScript, não será necessário configurar um servidor ou instalar dependências para a execução básica, desde que a implementação final não exija recursos adicionais.
